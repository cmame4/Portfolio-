# Yasmin Esmael — Personal Portfolio

Responsive, GitHub Pages-ready portfolio for Yasmin Esmael, a Grade 11 student at Kings Academy in Gondar, Ethiopia, exploring Computer Science and Information Technology.

## Features
- Bold feminine palette with saturated pink, purple, soft gradients and clean typography
- Responsive desktop/mobile navigation
- Hover lift and glow on skill cards, profile and project idea cards
- Floating elements, orbit animations, shimmer and scroll reveals
- Dark/light mode with browser preference saved locally
- Language selector: English, Amharic, Spanish, French, Dutch and Arabic (RTL layout)
- Expanded skills with honest learning-level labels
- One completed project and three clearly labelled future practice ideas
- Contact links use `jazmineali2010@gmail.com`

## Built with
HTML, CSS and JavaScript. Python is listed as a learning skill, not as a runtime requirement. JavaScript and UI design are presented as areas being explored.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a repository (for example, `yasmin-esmael-portfolio`).
2. Upload all files and folders, keeping `assets/yasmin-profile.png` in place.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Content accuracy
The weather dashboard, study planner and Python mini tools are labelled as future practice ideas, not completed projects. Confirm that Yasmin is comfortable publishing her photograph and email address before making the repository public.
